Link to Connect 隐私政策

一款在 macOS 上管理 App Store Connect（内购、截图、送审）的本地效率工具

最后更新：2026-10-05 生效日期：2026-10-05 开发者：YANGRONG

一句话结论

Link to Connect 不会向开发者或其服务器收集、上传或共享任何个人数据。

本应用是完全运行在你自己 Mac 上的本地工具。它只会把你主动提供的 App Store Connect API 凭据保存在本机，并在你操作时与苹果公司的 App Store Connect通信。 我们没有任何服务器、不嵌入任何第三方分析或广告 SDK、不进行任何追踪。

1. 概述

《Link to Connect》（下称"本应用"）是一款面向开发者的 macOS 效率工具，用于在本地批量创建 与管理 App Store Connect 内购项目、制作与上传应用截图、管理送审与版本信息。 本应用的核心设计原则之一是数据最小化与本机优先：除你主动发起的、指向苹果官方 App Store Connect API 的请求外，没有任何数据离开你的设备。

本隐私政策说明本应用如何处理信息，适用于通过 App Store 分发的 macOS 版本。 使用本应用即表示你理解并同意以下条款。

2. 我们收集的信息

我们不收集任何个人数据。

具体而言，以下类别的数据均不会被本应用或其开发者收集：

  • 姓名、邮箱、电话等身份标识；
  • 设备标识符、广告 ID（IDFA）、IP 地址（开发者侧）；
  • 使用行为、点击流、崩溃日志（开发者侧）；
  • 位置、通讯录、相册、麦克风、摄像头等敏感权限；
  • 你的 App Store Connect 账号内容或业务数据（除第 4 条所述、由你主动上传至苹果的部分外）。
依据 Apple「App 隐私」营养标签，本应用归类为「不收集数据」。 在 App Store Connect 提交时，请相应勾选：不收集任何数据类别。

3. 本机存储的数据

为让功能可用，本应用会在你自己的 Mac 本地保存少量配置，全部位于用户目录，不会同步到任何开发者服务器：

API 配置
~/Library/Application Support/LinkToConnect/config.json —— 保存你的 App Store Connect 发行者 ID、密钥 ID 与私钥文件路径。
私钥处理
私钥（.p8）仅记录其文件路径，内容不会被复制或外发；所有 API 请求签名均在本地用 Apple CryptoKit 完成。
界面偏好
通过系统 UserDefaults 保存本机使用偏好（如自动截图输出目录、截图工坊关联文件夹）。
临时产物
截图、拼图、导出文件按你选择的目录写入磁盘；应用不自动上传其中任何内容。

以上数据仅存在于你的设备，由 macOS 的账户权限与磁盘加密（如启用 FileVault）提供保护。 卸载应用时，这些文件可手动删除（见第 8 条）。

4. 与苹果公司的数据交互

本应用的功能依赖苹果官方服务，以下数据会在你主动操作时通过 macOS 原生网络请求发送至苹果：

  • App Store Connect API 调用：使用你提供的凭据，向 api.appstoreconnect.apple.com 发送内购创建、截图与元数据上传、版本与送审查询等请求。这些请求由苹果直接处理，受苹果隐私政策约束。
  • 截图与元数据上传：当你点击"上传到 App Store Connect"时，所选图片与字段会被提交至苹果的送审资源库。
  • 模拟器截图：自动截图功能调用本机 xcodebuild 与模拟器，产物保存在你指定的本地目录，仅在你的明确操作下上传。
本应用本身不扮演数据接收方，所有上述交互的接收方均为苹果公司。 关于苹果如何处理这些数据，请参阅 Apple 隐私政策。

5. 第三方服务与 SDK

本应用不集成任何第三方 SDK、分析工具、广告或崩溃上报服务。

全部功能使用 Apple 原生框架（SwiftUI、CryptoKit、Foundation、AppKit）实现， 零第三方依赖。除第 4 条所述的苹果官方接口外，不存在其他网络接收方。

6. 分析与追踪

本应用不进行任何形式的使用分析、行为追踪或广告归因。 没有埋点、没有遥测、没有第三方 Cookie 或像素。应用完全离线可用（除调用苹果 API 的功能外）。

7. 数据安全

  • 本地优先：凭据与配置永不离机至开发者侧。
  • 本地签名：App Store Connect API 请求使用 Apple CryptoKit 在设备端用你的私钥签名，私钥内容不离开本机。
  • 无传输中的开发者数据：与苹果之间的通信使用 HTTPS；开发者不在此过程中获得你的任何信息。
  • 你的责任：请妥善保管 config.json 与私钥文件，避免被未授权用户访问；建议启用 macOS FileVault 磁盘加密。

8. 你的权利与数据控制

由于本应用不向开发者收集任何数据，你无需提出"删除我的数据"请求。你可以随时在本机完全掌控相关数据：

  • 清除配置：删除 ~/Library/Application Support/LinkToConnect/ 目录即可移除全部保存的凭据与设置。
  • 撤销访问：在 App Store Connect 后台吊销对应的 API 密钥（.p8），本应用随即失去访问能力。
  • 卸载：将应用拖入废纸篓；如启用了"保留设置"，再按上条删除配置目录。

若你对数据处理仍有疑问，可通过第 11 条的方式联系我们。

9. 儿童隐私

本应用为开发者生产力工具，-rated 4+，不面向儿童，也不以任何年龄用户为数据收集对象。 我们不会有意收集任何人的个人数据。

10. 政策变更

如本应用未来引入任何会改变上述声明的功能（例如新增可选云同步或分析）， 我们将在此页面更新政策并标注新的"最后更新"日期，必要时在应用内提示。 重大变更将以合理方式通知。

Link to Connect — Privacy Policy

Summary

Link to Connect does not collect, upload, or share any personal data with the developer or any server.

This is a fully local macOS tool. It stores the App Store Connect API credentials you provide on your own Mac and communicates only with Apple's App Store Connect when you act. We operate no server, embed no third-party analytics or ad SDKs, and perform no tracking.

1. Overview

Link to Connect (the "App") is a macOS developer productivity tool for batch-managing App Store Connect in-app purchases, building and uploading screenshots, and managing submission and version metadata. Its core principle is data minimization and local-first: except for requests you explicitly initiate to Apple's official App Store Connect API, no data leaves your device.

2. Information We Collect

We collect no personal data. The following are not collected by the App or its developer:

  • Identity (name, email, phone);
  • Device identifiers, IDFA, or IP addresses (on the developer side);
  • Usage, clickstream, or crash logs (on the developer side);
  • Location, contacts, photos, microphone, or camera;
  • Your App Store Connect account content or business data (except what you actively upload to Apple per Section 4).
Under Apple's "App Privacy" nutrition labels, this App is classified as "Does not collect data."

3. Data Stored Locally

API config
~/Library/Application Support/LinkToConnect/config.json — your App Store Connect Issuer ID, Key ID, and private-key file path.
Private key
Only the file path of the .p8 key is recorded; its content is never copied or sent. All API signing is done locally with Apple CryptoKit.
Preferences
Local UI preferences (e.g., auto-screenshot output folder) via system UserDefaults.

4. Data Shared With Apple

When you act, the App sends data via native macOS networking to Apple:

  • App Store Connect API calls to api.appstoreconnect.apple.com for IAP creation, screenshot/metadata upload, and version/submission queries — handled directly by Apple.
  • Screenshot & metadata upload when you click "Upload to App Store Connect."
  • Simulator screenshots via local xcodebuild; uploaded only on your explicit action.

The App is not the data recipient; Apple is. See the Apple Privacy Policy.

5. Third-Party SDKs

None. The App uses only Apple native frameworks (SwiftUI, CryptoKit, Foundation, AppKit) with zero third-party dependencies. No analytics, ads, or crash-reporting SDKs.

6. Analytics & Tracking

No usage analytics, behavioral tracking, or ad attribution of any kind. The App is fully functional offline (except Apple API features).

7. Data Security

  • Local-first: credentials never leave your device to the developer.
  • On-device signing with Apple CryptoKit; the private key never leaves your Mac.
  • HTTPS to Apple; the developer receives none of your data in transit.
  • You should protect config.json and your .p8 key (e.g., enable FileVault).

8. Your Rights & Control

  • Clear config: delete ~/Library/Application Support/LinkToConnect/.
  • Revoke access: invalidate the API key (.p8) in App Store Connect.
  • Uninstall: move the App to Trash; delete the config folder if "keep settings" was enabled.

9. Children's Privacy

Rated 4+, a developer tool not directed at children, and collecting no personal data from any user.

Material changes will update this page with a new "Last updated" date and, where appropriate, an in-app notice.
